## 🚀 المميزات والخصائص

### 1. نظام الحماية ومكافحة التشارك (Triple-Factor Security Guard)
- **ربط ثلاثي إلزامي:** كل حساب طالب مربوط بـ `(Google ID + رقم الهاتف الموثق بالـ OTP + بصمة الجهاز Device Fingerprint)`.
- **قفل فوري للحساب (`status = LOCKED`):** في حال محاولة الدخول بنفس الرقم من حساب Google مختلف، أو من متصفح/جهاز جديد غير مصرح به.
- **تنبيه لحظي للأدمن:** إرسال رسالة واتساب فورية وإشعار باللوحة ببيانات المتسلل (الاسم، الهاتف، الجيميل الأصلي والمحاول، IP، البصمة).
- **فك الحظر الحصري:** الأدمن وحده يملك صلاحية فك الحظر، مع خيارات: (فك الحظر فقط / تغيير الجيميل المربوط / تصريح بجهاز جديد / مسح الأجهزة السابقة).

### 2. استضافة الفيديوهات والملفات المشفرة
- **مشغل فيديو Bunny Stream:** تشغيل HLS محمي بروابط توقيع مؤقتة (Signed Tokens) تنتهي تلقائياً لمنع برامج التحميل مثل IDM.
- **علامة مائية متحركة (Dynamic Moving Watermark):** تتحرك كل 4 ثوانٍ فوق الفيديو متضمنة `[اسم الطالب - رقم هاتفه - كود الجلسة]` لردع التصوير بالكاميرا.
- **عارض PDF مشفر:** عرض الملفات عبر Canvas محمي بروابط مؤقتة من Cloudflare R2 / S3 مع منع النسخ والطباعة (`Ctrl+P / Ctrl+S`).

### 3. محرك الامتحانات الذكي ومكافحة الغش (Exam Engine)
- **بنك الأسئلة للمادة:** يدعم أسئلة الاختيار من متعدد وصح/خطأ، مع درجات وتفسيرات الإجابات.
- **توزيع عشوائي ثابت (Deterministic PRNG Seed):** سحب $N$ سؤال عشوائياً لكل طالب مع خلط ترتيب الأسئلة والخيارات، وتثبيت النسخة في قاعدة البيانات لمنع تغيير الأسئلة عند الـ Refresh.
- **مؤقت سيرفري ونافذة دخول:** تحديد وقت البداية والنهاية، ومحاولة واحدة فقط للطالب غير قابلة للإعادة، وحساب الوقت بنسبة 100% على السيرفر مع تسليم تلقائي عند انتهاء المدة.
- **مراقبة مغادرة التبويب (Tab Switching Monitor):** كشف أي خروج من الامتحان أو فتح لتبويبات أخرى ورصد عدد المرات في تقرير الأدمن.

### 4. بوابات الدفع المصرية والاشتراكات
- **تكامل بوابة Paymob:** دعم البطاقات البنكية، والمحافظ الإلكترونية (فودافون كاش، أورنج، اتصالات، وي)، وانستا باي (InstaPay).
- **تأكيد مزدوج وتوقيع HMAC:** فحص الـ Webhook بتوقيع SHA-512 مع طلب تحقق مباشر من API قبل فتح المادة تلقائياً.
- **سعر موحد للمادة:** 50 جنيه مصري لكل مادة (قابل للتعديل بحرية من لوحة الأدمن).

## 💻 خطوات التثبيت والتشغيل المحلي

### 1. نسخ المستودع وتثبيت الاعتماديات
```bash
cd d:\eng-academy
npm install
```

### 2. إعداد ملف المتغيرات البيئية
قم بإنشاء ملف `.env` عبر نسخ `.env.example`:
```bash
copy .env.example .env
```

### 3. إنشاء جداول قاعدة البيانات وتوليد عميل Prisma
```bash
# إنشاء وتحديث الجداول في قاعدة بيانات PostgreSQL
npx prisma db push

# توليد عميل Prisma Client
npx prisma generate

# زراعة البيانات التجريبية (الدفعات، 5 مواد، أسئلة، طلاب تجريبيين، والأدمن)
npx ts-node prisma/seed.ts
```

### 4. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

## 🔑 دليل ربط Google OAuth 2.0

1. ادخل على **[Google Cloud Console](https://console.cloud.google.com/)**.
2. أنشئ مشروعاً جديداً باسم `Eng-Academy`.
3. من القائمة الجانبية: **APIs & Services** > **OAuth consent screen**:
   - اختر نوع المستخدم: **External**.
   - املأ اسم التطبيق وبريدك الإلكتروني.
   - في النطاقات (Scopes): أضف `.../auth/userinfo.email` و `.../auth/userinfo.profile`.
4. اذهب إلى **Credentials** > **Create Credentials** > **OAuth client ID**:
   - Application type: **Web application**.
   - Name: `Handasa Academy Web Client`.
   - في خانة **Authorized redirect URIs** أضف الرابطين التاليين:
     - محلياً: `http://localhost:3000/api/auth/callback/google`
     - عند النشر: `https://your-domain.com/api/auth/callback/google`
5. انسخ **Client ID** و **Client Secret** وضعهما في ملف `.env`:
   ```env
   GOOGLE_CLIENT_ID="xxxxxxxx.apps.googleusercontent.com"
   GOOGLE_CLIENT_SECRET="GOCSPX-xxxxxxxx"
   ```

## 💳 دليل ربط بوابة الدفع Paymob

1. سجل الدخول إلى لوحة تحكم **[Paymob Dashboard](https://accept.paymob.com/)**.
2. من تبويب **Settings** > **Account Info**: انسخ `API Key` وضعه في `PAYMOB_API_KEY`.
3. من تبويب **Developers** > **Payment Integrations**:
   - أنشئ Integration للبطاقات البنكية (Cards) وانسخ المعرّف إلى `PAYMOB_INTEGRATION_ID_CARD`.
   - أنشئ Integration للمحافظ الذكية (Mobile Wallets) وانسخ المعرّف إلى `PAYMOB_INTEGRATION_ID_WALLET`.
4. لتفعيل الـ Webhook التلقائي:
   - اذهب إلى **Developers** > **HMAC**: انسخ المفتاح السري وضعه في `PAYMOB_HMAC_SECRET`.
   - في إعدادات الـ Transaction Processed Callback في لوحة Paymob، ضع الرابط:
     `https://your-domain.com/api/webhooks/paymob`

## 🎥 دليل ربط Bunny Stream

1. ادخل على حسابك في **[Bunny.net](https://bunny.net/)** وتوجه إلى **Stream**.
2. أنشئ **Video Library** جديدة باسم `Engineering-Lectures`.
3. انسخ المعرّفات التالية من صفحة **API & Keys** في مكتبة الفيديو:
   - `BUNNY_LIBRARY_ID` (معرف المكتبة المكون من أرقام).
   - `BUNNY_API_KEY` (مفتاح الـ API الرئيسي).
   - `BUNNY_TOKEN_AUTH_KEY` (مفتاح الـ Token Authentication لتوقيع الروابط).
   - `BUNNY_CDN_HOSTNAME` (رابط CDN الخاص بمكتبتك مثل `vz-xxxx.b-cdn.net`).
4. فعّل خيار **Token Authentication** داخل إعدادات الأمان في Bunny لضمان عدم تشغيل أي فيديو بروابط غير موقّعة من موقعك.

## 💬 دليل ربط Meta WhatsApp Cloud API

1. ادخل على **[Meta for Developers](https://developers.facebook.com/)**.
2. أنشئ تطبيقاً من نوع **Business** وأضف إليه منتج **WhatsApp**.
3. في إعدادات واجهة API لـ WhatsApp:
   - انسخ **Phone number ID** وضعه في `WHATSAPP_PHONE_NUMBER_ID`.
   - انسخ **WhatsApp Business Account ID** وضعه في `WHATSAPP_BUSINESS_ACCOUNT_ID`.
   - استخرج **Permanent System User Access Token** وضعه في `WHATSAPP_ACCESS_TOKEN`.
4. يمكنك إرسال الرسائل إلى 1000 محادثة شهرياً مجاناً تماماً عبر Meta الرسمية.

## 🌐 دليل النشر (Production)

### الخيار 1: النشر السحابي (Vercel + Neon PostgreSQL) - الأسرع والأسهل
1. أنشئ قاعدة بيانات PostgreSQL مجانية على **[Neon.tech](https://neon.tech/)** وانسخ رابط الاتصال `DATABASE_URL`.
2. ارفع المشروع على حسابك في **GitHub**.
3. اربط المستودع في **[Vercel](https://vercel.com/)**.
4. أضف جميع المتغيرات البيئية من ملف `.env.example` إلى إعدادات Vercel Environment Variables.
5. شغّل أمر الـ Seed مرة واحدة لزراعة البيانات الأولية عبر لوحة Neon SQL Editor أو من سطر الأوامر.

### الخيار 2: النشر على سيرفر خاص (VPS - Ubuntu + Nginx + PM2)
```bash
# 1. تثبيت Node.js و PM2
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs nginx
sudo npm install -g pm2

# 2. بناء المشروع وتشغيله
npm run build
pm2 start npm --name "eng-academy" -- start

# 3. إعداد Nginx كـ Reverse Proxy على المنفذ 3000 مع تفعيل شهادة SSL المجانية (Certbot)
sudo certbot --nginx -d your-domain.com
```
